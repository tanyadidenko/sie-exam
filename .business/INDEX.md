# SIE EXAM — Бизнес-контекст

## 📋 Описание проекта

**SIE EXAM Trainer** — веб-приложение для подготовки к экзамену SIE (Securities Industry Essentials).

**Целевая аудитория:** Сын Татьяны, который готовится к сдаче экзамена SIE для работы в финансовой индустрии США.

**Проблема:** Экзамен SIE сложный, требует знания множества тем по финансовым рынкам, регулированию, продуктам и практикам. Нужен систематический подход к подготовке с отслеживанием прогресса и повторением проблемных тем.

**Решение:** Мобильное веб-приложение (PWA) с:
- Базой вопросов по всем темам экзамена
- Системой прогресса и статистики
- Интервальным повторением (SM-2) для проблемных тем
- Различными режимами тренировки
- Геймификацией (достижения, ежедневные цели)

## 🎯 Цели проекта

1. **Основная цель:** Подготовить сына к успешной сдаче экзамена SIE (проходной балл 70%)
2. **Техническая цель:** Создать мобильное PWA-приложение с удобным интерфейсом
3. **Методическая цель:** Использовать научно обоснованные методы обучения (интервальное повторение, адаптивное обучение)

## 📊 Метрики успеха

- Сын сдает экзамен SIE с результатом ≥70%
- Приложение используется ежедневно (streak ≥ 7 дней)
- Прогресс по всем темам ≥80% перед экзаменом
- Количество решенных вопросов ≥500 перед экзаменом

## 🏗️ Технологический стек

**Backend:**
- Node.js 20+ (Express.js)
- SQLite (better-sqlite3) — база данных пользователей и прогресса
- Multer — загрузка файлов (если нужно)

**Frontend:**
- Vanilla JavaScript (без фреймворков)
- HTML5 + CSS3
- PWA (Progressive Web App)
- Service Worker для оффлайн-работы

**Инфраструктура:**
- Docker + Docker Compose
- Nginx reverse proxy
- Let's Encrypt SSL

##  Этапы проекта

- Изучить структуру экзамена SIE
