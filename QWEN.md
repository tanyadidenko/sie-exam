## Важнейшие правила

### 🔴 БЕЗОПАСНОСТЬ — ЗАПРЕТ КОММИТА СЕКРЕТОВ

1. **Никогда** не коммить `.env`, `.env.server`, `.env.*` файлы в git.
2. **Никогда** не хардкодить пароли, API-ключи, токены в коде (.py, .sh, .bat, .ps1, .js).
3. **Никогда** не передавать файлы с секретами на GitHub.
4. GitHub PAT токен **НЕ** должен быть зашит в `.git/config` — использовать SSH.
5. Перед каждым коммитом проверять `git status` на наличие секретов.

## 📚 О проекте SIE EXAM

**Цель:** Создать веб-приложение тренажёр для подготовки к экзамену SIE (Securities Industry Essentials).

**Экзамен SIE:**
- Базовый экзамен для работы в финансовой индустрии США
- Проводится FINRA (Financial Industry Regulatory Authority)
- 75 вопросов, 1 час 45 минут
- Проходной балл: 70%
- Темы: рынки ценных бумаг, регулирование, продукты, практики

**Приложение должно:**
- Содержать базу вопросов по всем темам экзамена
- Иметь систему прогресса и отслеживания результатов
- Использовать интервальное повторение (SM-2) для проблемных тем
- Быть мобильным (PWA) — сын будет тренироваться на телефоне
- Иметь режимы: практика по темам, полный тест, повторение ошибок
